# Tetraedro - Solidos de Platao

Tetraedro regular feito em OpenGL com Python: 4 faces coloridas, eixos X, Y e Z
de referencia e rotacao continua.

## Como rodar

```bash
pip install -r requirements.txt
```

```bash
python tetraedro.py
```

## Controles

- `X`, `Y`, `Z` - troca o eixo de rotacao
- `A` - gira nos tres eixos
- `Espaco` - pausa
- `+` / `-` - velocidade
- `R` - zera os angulos
- `Q` ou `Esc` - sai
